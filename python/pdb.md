# Команды pdb (Python Debugger)

## Управление выполнением

| Команда    | Сокращение | Действие                                 |
| ---------- | ---------- | ---------------------------------------- |
| `step`     | `s`        | Шагнуть **внутрь** функции               |
| `next`     | `n`        | Выполнить строку **не заходя** в функции |
| `return`   | `r`        | Выполнить до возврата из функции         |
| `continue` | `c`        | Продолжить до следующей точки останова   |
| `until`    | `unt`      | Выполнять до строки с номером N          |
| `jump`     | `j`        | Перепрыгнуть на указанную строку         |
| `quit`     | `q`        | Выйти из отладчика                       |

## Просмотр переменных

| Команда          | Действие                           |
| ---------------- | ---------------------------------- |
| `p <выражение>`  | Вывести значение                   |
| `pp <выражение>` | Вывести в "красивом" формате       |
| `locals()`       | Показать все локальные переменные  |
| `globals()`      | Показать все глобальные переменные |
| `args`           | `a`                                |

## Навигация по стеку

| Команда    | Сокращение | Действие                           |
| ---------- | ---------- | ---------------------------------- |
| `where`    | `w`        | Показать стек вызовов              |
| `up`       | `u`        | Подняться по стеку                 |
| `down`     | `d`        | Опуститься по стеку                |
| `list`     | `l`        | Показать код вокруг текущей строки |
| `longlist` | `ll`       | Показать всю текущую функцию       |

## Точки останова

| Команда     | Сокращение | Действие                              |
| ----------- | ---------- | ------------------------------------- |
| `break`     | `b`        | Установить точку останова             |
| `clear`     | `cl`       | Удалить точки останова                |
| `disable`   | -          | Отключить точку останова              |
| `enable`    | -          | Включить точку останова               |
| `condition` | -          | Установить условие для точки останова |

## Справка

| Команда          | Действие                      |
| ---------------- | ----------------------------- |
| `help`           | `h`                           |
| `help <команда>` | Справка по конкретной команде |
