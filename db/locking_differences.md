# Чем отличаются друг от друга блокировки баз данных

В управлении базами данных блокировки - это механизмы, которые предотвращают
одновременный доступ к данным, обеспечивая их целостность и согласованность.

Основные типы блокировок:

🔺 Shared Lock: позволяет нескольким транзакциям одновременно читать ресурс, но
не модифицировать его.

🔺 Exclusive Lock: позволяет транзакции как читать, так и модифицировать ресурс.

🔺 Update Lock: используется для предотвращения взаимоблокировки, когда
транзакция намеревается обновить ресурс.

🔺 Schema Lock: используется для защиты структуры объектов базы данных.

🔺 Bulk Update Lock: используется во время массовых вставок.

🔺 Key-Range Lock: используется в индексированных данных для предотвращения
фантомных чтений.

🔺 Row-Level Lock: блокирует конкретную строку в таблице.

🔺 Page-Level Lock: блокирует конкретную страницу (фиксированный блок данных) в
базе данных.

🔺 Table-Level Lock: блокирует всю таблицу.
